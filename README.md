# 집필온 소개 페이지

집필온의 실제 서비스 색상과 현재 운영 기능을 바탕으로 만든 단일 HTML 소개 페이지입니다.

## 공개 페이지

GitHub Pages를 통해 공개합니다.

## 구성

- `index.html` — 외부 빌드 과정 없이 바로 열리는 단일 소개 페이지
- 집필온 운영 서비스 연결: <https://jipilon-workspace.vercel.app>

## 운영 원칙

- 현재 제공 기능과 확장 준비 기능을 구분해 표시합니다.
- 작성 중 원고의 비공개, 근거 기반 시장 검토, 작가의 내보내기 권리를 핵심 원칙으로 둡니다.
