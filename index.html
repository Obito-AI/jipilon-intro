집필온에서 하는 일

무엇을 쓸지 정하고,
실제 원고를 씁니다.

쓸거리와 독자를 정한 다음 목차를 만들고, 한 꼭지씩 원고를 채웁니다. 쓰다가 고쳐도 되고, 이전 글로 돌아가도 됩니다.

01

쓸 주제를 정합니다

키워드 하나에서 여러 주제를 찾아봅니다. 검색 추세와 직접 찾은 시장 정보, 비교 가격을 따로 보면서 무엇을 쓸지 좁혀갑니다.

  • 3단계 주제 찾기
  • 검색 추세 확인
  • 가격 비교
02

목차를 짜고 바로 씁니다

목차를 만들면 각 항목이 원고 페이지가 됩니다. 혼자 쓰는 책도, 여러 사람이 나눠 쓰는 책도 같은 자리에서 관리할 수 있습니다.

  • 목차 만들기
  • 원고 편집
  • 담당자 지정
03

쓰던 글을 놓치지 않습니다

지금 저장됐는지 화면에서 바로 확인할 수 있습니다. 수정한 내용은 버전으로 남기고, 필요하면 이전 원고를 다시 불러옵니다.

  • 자동 저장
  • 저장 상태 확인
  • 이전 버전 복구
04

내 말투로 고칩니다

어색한 문장을 찾아 바로 이동하고, 바꾼 문장은 원문과 비교합니다. 마음에 들지 않으면 실행 취소로 되돌릴 수 있습니다.

  • 문체 검사
  • 문장 바꾸기
  • 실행 취소·다시 실행

처음부터 끝까지

아이디어 하나로 시작해,
원고 한 벌을 만듭니다.

처음부터 잘 쓸 필요는 없습니다. 누구에게 어떤 이야기를 할지 정하고, 목차를 만든 뒤, 한 꼭지씩 채우면 됩니다.

01

쓸 거리를 좁힙니다

떠오른 키워드를 몇 가지 주제로 바꿔보고, 누가 읽을지와 어떤 도움이 될지를 함께 적습니다.

02

책의 뼈대를 잡습니다

하고 싶은 이야기를 장과 절로 나눕니다. 목차마다 원고 페이지가 생기니 바로 쓰기 시작할 수 있습니다.

03

한 꼭지씩 채웁니다

쓴 글은 자동으로 저장됩니다. 어색한 문장을 고치고, 잘못 바꿨다면 이전 버전으로 돌아갑니다.

04

파일로 꺼냅니다

완성한 원고를 PDF, Markdown, HWPX로 저장하고 표지와 책 소개를 준비합니다.

우리가 먼저 지키는 것

글 쓰는 사람이
불안하지 않도록.

“쓰던 글이 사라지지 않고, 내가 공개하기 전에는 남에게 보이지 않는 것. 집필 도구라면 먼저 지켜야 할 기본입니다.”

공개하기 전까지는 비공개

작성 중인 제목과 본문, 검토 메모는 출간 신청이나 공개를 직접 선택하기 전에는 밖으로 보이지 않습니다.

숫자는 부풀리지 않기

검색 추세를 검색량이라고 부르거나, 유사 도서 수를 판매량처럼 말하지 않습니다. 모르는 값은 미산정으로 남깁니다.

AI가 고쳐도 결정은 내가

AI가 바꾼 문장은 원문과 비교해서 보고, 마음에 들지 않으면 되돌릴 수 있습니다.
